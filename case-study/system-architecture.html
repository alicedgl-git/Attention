Signal-Based Outreach System — Architecture

Scheduled Claude Code agent · runs every Monday at 6 AM · end-to-end in under 30 minutes. One orchestrator + three Python pipeline stages + one LLM hook agent. Honest agent count: 2. The pipeline reads from Salesforce, scores accounts on Fit × Intent, and routes them by owner — Tier 1 to a SDR for personalized compose, Tier 2 to automated templated outreach.
