ATTENTION · GTM ENGINEERING Slide 02 / 07

The Thesis

1M companies → 50k ICP → ~250 actions/week.

Track 10 buying signals weekly. Score on a 100-point scale (Intent + multi-signal bonus). Cross with Fit Score. Route via 2×2 matrix to 4 tiers — SDR-personalized, automated outbound, watchlist, or skip. Cadence library prescribes the message; AI generates only the first hook from signal evidence.

Part 1

Signals

10 weighted signals across 3 categories — first-party intent, trigger events, state.

Part 2

Scoring

Fit × Intent matrix. Multi-signal bonus rewards convergence.

Part 3

System

Claude Code orchestrator + 3 Python pipeline stages + 1 LLM hook agent. Two SDR surfaces.

Part 4

Rollout

30-day build → 4-week pilot → A/B vs. control. Reply rate is the north star.

PART 4 · ROLLOUT & MEASUREMENT Slide 07 / 07

30-day plan · KPIs · feedback · Phase 2.

Week 1

Talk to the sales team

  • How do they cut territory today?
  • How do they run outbound today — what works, what's broken?
  • Audit where the data sits: SF objects, Clay workflows, Snowflake schemas, Amplemarket setup
  • Walk the team through the project to validate the approach
Week 2

Build & test myself

  • Wire Stage 1 — signal collection across 10+ APIs
  • Wire Stage 2 — scoring math + 2×2 matrix
  • Wire Stage 3 — LLM hook agent + Amplemarket cadence connections
  • Test end-to-end on a 100-account sample · validate AI hook quality
Week 3

First real-time test

  • Monday: full pipeline runs on the pilot territory
  • Daily 15-min standup with pilot SDRs
  • Iterate on signals, hooks, cadences based on SDR feedback
  • Friday: first weekly report
Week 4

System ready

  • Pipeline running smoothly · no critical bugs
  • Onboard remaining SDRs in pilot territory
  • Lock the measurement dashboard (Looker / Mode → Snowflake + SF)
Measurement · 5 KPIs
  • Scored accounts → meetings booked — overall system conversion
  • Reply rate per cadence + per signal — message resonance + signal quality
  • Sequencing rate (% of Tier 1 actually actioned by SDRs) — tool adoption
  • Coverage % (% of accounts firing ≥1 signal weekly) — pipeline health
  • Pipeline → closed-won (90d cohort) — revenue impact

Tracked in a Looker (or Mode) dashboard pulling from Snowflake (signal + scoring history) and Salesforce (outcomes + adoption). Refresh daily.

Feedback loops · day 1
  • Cadence: per-cadence reply rate (from Amplemarket webhooks) → A/B variants, retire weak ones
  • Agent: LLM hook quality tracked per reply → prompt tuning
  • Outcome: AE tags signal that drove closed-won → trains Phase 2 weight calibration
  • Human: weekly SDR check-in · monthly leadership · quarterly CEO/CRO
Phase 2 · scoring on real data

Past + ongoing data → smarter weights

After 90 days of pilot data, replace the heuristic Part 1 weights with empirical ones learned via logistic regression on signals fired → won/lost.

Refresh quarterly as more outcomes accumulate.
